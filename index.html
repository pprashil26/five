How to Use Five

1. Capture quickly

Tap + Task, choose a context, enter the task title, and add a date only when the task genuinely belongs to a day.

Use Save + Next for batch capture. Five remembers the last context and automatically creates the first action from the task title.

2. Process Inbox

Inbox contains unpinned, undated tasks in All. Tap Review to process one task at a time, then add a date, change its context, activate it, move it to Waiting, archive it, or continue to the next task.

3. Activate only a few tasks

Tap ⚡ on an All task to move it directly to Active. Active is deliberately limited to five tasks. Duration estimates show the workload beside the Active count.

4. Use dates sparingly

Today shows overdue and due-today tasks. Dated shows every dated All task. Leave flexible work undated so the lists stay meaningful.

5. Work by context

Contexts group tasks by where or how they can be done, such as @CALL, @COMPUTER, @ONLINE, @ERRANDS, @HOME, and @AGENDA. Use + Contexts on desktop, or the compact + on mobile, to add, rename, or reorder contexts.

6. Complete and organise

Open a task with ✎ to add descriptions, actions, dates, duration, or change status. Use Waiting for delegated or blocked work, and Archive for completed or retained tasks.

7. Protect your data

Five saves locally using verified browser storage and creates Recovery snapshots. Use Backup regularly to keep an external JSON copy, especially before browser cleanup or moving devices.
